# Provisionnement d'un livre

Avant de rédiger un livre géographique, on estime le nombre de paragraphes à partir de son graphe de hubs.

`P ≈ H + 2O + L + E + S + I`

| Terme | Ce qu'il compte |
| --- | --- |
| `H` | Les hubs : un paragraphe d'orientation chacun. |
| `O` | Les possibilités locales : un volet **Discovery** et un volet **JdR solo** chacune, d'où le facteur 2. |
| `L` | Les liaisons distinctes entre hubs : un paragraphe de trajet bidirectionnel chacune. |
| `E` | Les situations de trajet, avec leurs conséquences et leurs retours. |
| `S` | Les scènes particulières non comptées ailleurs : mythes, esprits, grimoires, compréhensions, relations. |
| `I` | Les entrées et sorties : création locale, arrivées depuis d'autres livres, transitions. |

## Limites connues

- Deux volets d'une même possibilité peuvent partager un paragraphe, ou au contraire demander des paragraphes d'issue supplémentaires.
- Le nombre des situations de trajet (`E`), leurs renvois et leur distribution se décident au moment du provisionnement.
