# §046 — Wilmskirk

Wilmskirk est une étape du sud de Sartar où se croisent voyageurs, marchands et habitants des terres voisines. Les réseaux commerciaux qui remontent vers Jonstown rencontrent ici ceux qui regardent vers le Pays Saint.

## Explorer

- **Si vous possédez la relation `RELATION-HORNOS` ou la mémoire `SARTAR-PISTE-GOLDGOTTI`**, vous savez comment chercher les gens de **Goldgotti** : allez au [§240](./240.md).
- Le marché, les auberges, les temples et les institutions de Wilmskirk seront développés en scènes propres.
