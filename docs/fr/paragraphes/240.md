# §240 — Le réseau de Goldgotti

Dans une maison de commerce de Wilmskirk, vous participez à une discussion avec les agents du réseau de GOLDGOTTI. Ils vous expliquent comment leurs convois et leurs messages circulent vers le Pays Saint. Vous avez réellement rencontré ce réseau ; entourez GOLDGOTTI, s'il n'a pas déjà de marque. Un nom seulement entendu à Jonstown n'aurait pas suffi.

Si DARVAST HORNOS est entouré, l'autorisation que vous a donnée Darvast change votre accueil : un responsable prend votre nom et vous présente à quelques habitués. Vous pouvez vous prévaloir de cette recommandation lors d'un prochain passage. Aucun autre mot-clé n'est nécessaire.

Si DARVAST HORNOS est barré, les agents connaissent le différend. Vous pouvez discuter des routes, mais ils refusent de vous traiter comme un contact privilégié. Le nom GOLDGOTTI reste entouré : vous avez découvert le réseau sans obtenir sa confiance.

Si DARVAST HORNOS n'a aucune marque, vous trouvez les agents grâce à votre **piste-goldgotti** et échangez avec eux sans recommandation. Vous pouvez désormais situer leur maison.

Retournez à [Wilmskirk, §046](./046.md).
