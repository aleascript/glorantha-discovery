# Les livres

## Livres géographiques

La bibliothèque est **extensible sans limite**. Il n'y a ni ordre imposé, ni « une Vision par territoire » : chaque livre accueille un personnage de chacune des quatre Visions. Une partie ne visitera pas nécessairement tous les volumes.
