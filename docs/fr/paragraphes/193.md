# §193 — Boldhome

Vous pénétrez dans BOLDHOME. La capitale de Sartar se déploie sur les hauteurs : des voies montent vers les bâtiments officiels, les sanctuaires et les quartiers habités. Malgré les autorités lunaires, les habitants poursuivent leurs échanges et leurs rites.
