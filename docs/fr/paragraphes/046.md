# §046 — Wilmskirk

Vous arrivez à WILMSKIRK, où les marchandises qui descendent du nord croisent les voyageurs et les échanges tournés vers le Pays Saint. Les boutiques, les chargements et les propos entendus aux portes vous font connaître ce carrefour autrement que par une rumeur.

## Explorer

Si DARVAST HORNOS est **entouré**, vous pouvez vous présenter à la maison de commerce de son partenaire Goldgotti : [§240](./240.md).

Si **piste-goldgotti** est cochée, vous connaissez aussi l'adresse de cette maison et pouvez vous y présenter : [§240](./240.md). Cette entrée reste accessible même si DARVAST HORNOS est barré.

Les autres auberges, temples et marchés seront approfondis ultérieurement.
