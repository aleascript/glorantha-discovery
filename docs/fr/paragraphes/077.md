# §077 — Jonstown

Vous arrivez à JONSTOWN. La ville occupe trois collines au-dessus des routes et du Boranini. Sur les hauteurs se dressent les bâtiments de l'ancienne ville ; plus bas, les ateliers, marchés et maisons accueillent habitants et voyageurs. Les soldats lunaires surveillent les portes, tandis que les institutions sartarites poursuivent leur activité.

Vous avez parcouru les rues, entendu les disputes des marchands et vu les scribes se diriger vers les bâtiments de Lhankor Mhy. Cette ville n'est plus pour vous un nom entendu au loin.
