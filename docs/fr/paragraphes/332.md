# §332 — La bibliothèque de Jonstown

Vous rencontrez un scribe des Sages Libres devant le temple-bibliothèque de LHANKOR MHY. Il vous explique que les archives ne sont pas ouvertes à la promenade : la communauté des sages contrôle les rouleaux et les copies, mais reçoit les demandes des visiteurs.

Choisissez une conversation. Vous pourrez revenir pour l'autre. Si vous avez déjà coché le mot-clé correspondant, la conversation peut être reprise sans nouvel acquis.

## Entendre un récit

Le scribe vous récite une version accessible de la quête des PORTEURS-DE-LUMIÈRE. Il évoque les compagnons d'Orlanth, leur descente dans les ténèbres et la recherche d'un nouvel accord pour le monde. Vous n'apprenez ni les secrets d'un culte ni les gestes d'un rituel ; vous avez pourtant entendu un récit suffisamment entier pour le reconnaître ailleurs.

## Parler des routes commerciales

Le scribe sort un registre de marchands, vous montre comment les frères Hornos organisent le commerce de Jonstown et vous raconte leurs liens avec Goldgotti, négociant de Wilmskirk. Cette conversation vécue vous donne **Piste-Hornos** : au marché, vous savez quelle maison de commerce chercher. Avoir entendu le nom de Goldgotti ne signifie pas l'avoir rencontré.
