# Boldhome

Boldhome est le cœur politique du royaume de Sartar et un lieu dont la signification dépasse les fonctions administratives. Selon l'époque choisie pour le jeu, la présence lunaire et les rapports de pouvoir changent fortement : **aucune période précise n'a encore été fixée pour le POC**.

**À développer :** un lieu sacré, une voix contradictoire sur le pouvoir et une conséquence persistante d'une rencontre.
