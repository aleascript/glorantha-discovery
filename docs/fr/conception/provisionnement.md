# Provisionnement d'un livre

Avant de rédiger un livre géographique, on estime le nombre de paragraphes à partir de son graphe de lieux.

`P ≈ L + 2R + T + E + S + I`

| Terme | Ce qu'il compte |
| --- | --- |
| `L` | Les lieux : un paragraphe d'orientation chacun. |
| `R` | Les rencontres : un volet **Discovery** et un volet **JdR solo** chacune, d'où le facteur 2. |
| `T` | Les trajets, c'est-à-dire les liaisons distinctes entre lieux : un paragraphe bidirectionnel chacun. |
| `E` | Les événements de voyage, avec leurs conséquences et leurs retours. |
| `S` | Les scènes particulières non comptées ailleurs : mythes, esprits, grimoires, compréhensions, relations. |
| `I` | Les entrées et sorties : création locale, arrivées depuis d'autres livres, transitions. |

## Limites connues

- Deux volets d'une même rencontre peuvent partager un paragraphe, ou au contraire demander des paragraphes d'issue supplémentaires.
- Le nombre des événements de voyage (`E`), leurs renvois et leur distribution se décident au moment du provisionnement.
