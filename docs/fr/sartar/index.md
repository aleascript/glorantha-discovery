# Explorer Sartar

**Prototype de navigation géographique — contenu provisoire.** Le graphe privilégie une boucle de parcours restreinte, pas une description exhaustive du royaume.

Les routes royales relient Jonstown, Boldhome et Wilmskirk ; une route part également de Wilmskirk vers Duck Point. Ces liaisons sont documentées dans *Sartar: Kingdom of Heroes*, section « Traveling Through Sartar ».

## Lieux ouverts

- [Jonstown](./jonstown.md) — savoir, échanges et bibliothèque.
- [Boldhome](./boldhome.md) — capitale et centre politique.
- [Wilmskirk](./wilmskirk.md) — ville et carrefour vers le sud.
- [Duck Point](./duck-point.md) — porte d'entrée vers le monde des Durulz et les abords du Marais.

Le premier parcours conseillé commence à [Jonstown](./jonstown.md). Les flèches des routes sont bidirectionnelles : il est possible de revenir en arrière.

## À valider

Les temps précis par tronçon, les événements par type de terrain, le choix d'une période historique, les conditions de passage entre clans et les mémoires de retour ne sont **pas encore arrêtés**.
